# [Client Name] Theme

The theme works only with Shopify CLI.

### How to run the proyect?
1. Copy this repository ```git clone https://github.com/tonchiserra/shopify-cli-repo-boilerplate.git```
2. Replace 'client-name' and 'client-store' ```into package.json``` file.
3. Install the dependencies ```npm install```
4. Run ```npm run pull-theme```
5. Run ```npm start```
